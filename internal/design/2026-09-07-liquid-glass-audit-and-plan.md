# 正方教务助手：液态玻璃、动效、图标与布局调研及完整实施计划

日期：2026-09-07。调研对象：`D:/zfapk` 当前 `main` 工作区及其已有未提交改动，应用版本配置为 `1.0.73`。

本文是调研结论和后续实施规格。应用实现尚未按本文修改。本轮不使用子代理。

## 1. 已确定的方向与完成标准

### 1.1 用户已确定的选择

- 风格为 Apple 系统感加应用自己的细节，液态玻璃必须有明显辨识度，操作必须连续、跟手。
- 保留课程、课表、抢课、成绩、设置五个主入口，允许重排页内内容、工具栏、列表和弹层。
- 保留底栏滚动收缩为当前标签胶囊的行为，修整触发规则和收缩过程。
- 内部图标采用圆润线性轮廓，选中时局部填充，并有各自的短动画。
- 保留选择器的分裂、拉颈、分离、吸收效果，以及底栏透镜和按钮的跟手形变。

### 1.2 设计判断

**现阶段不需要普遍增加玻璃覆盖面积。应该完善现有玻璃的来源、层次、交互和运行效率。** 当前已经有真实折射管线、模糊、色散、融合几何和弹簧控制；继续给正文卡片加透镜，会提高采样成本并削弱信息层级。

玻璃的主要位置确定为底栏、悬浮工具、分段选择、选择器展开层和模态边界。课程、成绩、设置行及输入正文使用稳定、可读的内容表面。对话框中的普通行和按钮不再各自叠一层完整玻璃，选中的活动控件可以短暂液化。这符合 Apple 对导航控制层及避免重复玻璃叠加的说明。[Apple：Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)

四个核心体验必须成立：

1. 静止时可以辨认玻璃的透底、厚度和边缘反射，文字清晰，页面不持续运动。
2. 按下、拖动、松手是同一个动作，玻璃、轮廓、高光、图标没有各自错位的阶段。
3. 快速连点、反向拖动、取消手势可以接续当前状态，不跳回初始帧，不误触业务操作。
4. 切页回来仍处于原先的浏览位置，性能优化不通过普遍关闭折射或删除液态特征达标。

### 1.3 本轮边界

覆盖五个主页面、可选/已选视图、传统与新教务适配分支、登录、引导、课表设置、学校适配/历史等辅助页面，以及共用控件和弹层。保留已有品牌主色、用户壁纸、课程分类色及业务能力差异。

桌面图标本轮使用现有品牌资产；登录和引导统一使用该资产。教务协议、抢课调度、配额规则、账号存储和网络请求语义不属于视觉重构范围。涉及数据状态的调整只解决保存、失效、加载展示和账号隔离。

## 3. 当前实现的实际结构

### 3.1 材质不是同一条实现

| 部分 | 当前实现 | 后续处理原则 |
| --- | --- | --- |
| `GlassMaterialRole` | Navigation、Control、Modal、Interactive 四类配方 | 继续使用，统一调用点的额外参数，避免另建一套重叠主题 |
| 主界面底栏与透镜 | Backdrop 来源、模糊轨道、选中透镜、独立前景和隐藏 tint 采样层 | 保留构成，统一运动与图标状态 |
| API 33+ | 平台 RuntimeShader/AGSL，由 Backdrop 执行实时折射 | 保持现有主路径，避免引入 CPU 位图读回 |
| API 31/32 | 共享 EGL 环境、区域来源纹理、每个元素独占 FBO/输出位图 | 保留真实折射，修复重复提交和来源更新契约 |
| API 24-30/显式关闭玻璃 | 非 Backdrop 的表面、轮廓与常规动效 | 保持功能、布局和状态反馈，不声称拥有同等实时折射 |
| `GlassKit` 内容卡片 | 多数是透明度混合、边框、普通绘制 | 作为内容表面使用，名称不代表运行着透镜 |
| 登录、引导、独立窗口 | 各自建设部分 Backdrop/弹层环境 | 补齐按窗口隔离的环境，避免取到错误窗口的来源 |

主界面普通控件大多采样壁纸；底栏采样壁纸与页面；部分页面另有局部内容来源。改变透明度之前，必须先确认控件应该采到什么。背景均匀时，增加折射量不会凭空增加纹理，玻璃仍应依靠边缘反射和几何表现厚度。

参考：[材质角色](../../app/src/main/java/com/tyust/course/ui/system/GlassMaterial.kt#L11)、[既有 API 31/32 管线说明](../glass-lens-api32.md)。说明中的历史性能数字不是本轮实测结果。

### 3.2 需要保留的工程约束

- 玻璃目标不在自身采样来源的子树内，禁止自采样；隐藏 tint 副本继续排除可访问性语义。
- 来源纹理按区域共享，渲染目标和输出位图按元素独占，避免一个控件显示另一个控件的结果。
- API 31/32 与 API 33+ 使用同一套实测尺寸、光学比例和形变，轮廓、折射、前景坐标一致。
- 保持底栏选中透镜现有 `NavIndicatorRefractionFloor = 0f` 的静止终态，不能为“更玻璃”统一加回静止色边。轨道本身仍提供玻璃材质，交互时透镜恢复明显折射。
- 选择器保留两自由度物理及 SDF 融合，不以普通下拉淡入替换，不恢复已经去掉的静止连接细线。
- 底栏几何与内容安全留白继续同源计算；折叠头部不能通过重复扣除 inset 使内容跳动。

## 5. 共用组件的实施规格

### 5.1 渲染调度与来源更新

1. 为 GL 请求建立明确的请求标识，包含来源版本、目标尺寸、采样区域和光学参数。来源没有变化且请求相同时复用现有输出，不再产生新的绘制失效。
2. 保留“同一目标至多一个排队任务、更新覆盖为最新请求”的策略；渲染完成后若还有更新请求，继续处理最新请求，不依赖无限回调循环来保证最后一帧。
3. 来源版本变化必须使相同光学参数重新出帧。主题、壁纸解码完成、页面内容提交、选项变化和滚动结束都有明确的失效事件。
4. 保留来源纹理缓存和异步渲染，不在 UI 绘制中同步等待 GPU，不引入每帧全屏位图读回。优先复用既有区域，不为每枚按钮建立独立全屏来源。
5. API 31/32 背景滚动快照先保留现有 100ms 限频，停止后补拍；控件的几何、采样窗口及光学参数仍逐帧更新。正式验收单独检查该来源延迟，不能将它与“异步输出约上一帧”混为一谈。
6. 每个新出现的透镜在首帧结果可用前保留正常材质底色/模糊底，不依赖整个区域曾经出过帧。失败状态可观察，失败控件切回当前主题材质，避免永久空白或永远显示旧壁纸。
7. 工具组速度衰减只在速度非零时订阅帧钟；按实际 `dt` 衰减，采用 `pow(0.78, dtSeconds * 60)` 保持原 60Hz 衰减基线。位移速度统一使用单调时间，活动结束停止唤醒。

### 5.2 玻璃视觉规格

| 状态/层级 | 明确的设计规则 |
| --- | --- |
| 静止导航 | 保留轨道透底、细边缘反射和软阴影；选中透镜维持既有零静止折射终态 |
| 按下 | 一开始就有触点附近的高光和形变，表面适度变透，增加折射；前景比玻璃变形更小 |
| 拖动 | 几何、光学采样和前景共享同一状态；沿运动方向拉伸、垂直方向收缩，保留速度带来的流动感 |
| 松手 | 保留一次可见回弹，色散、高光、形变共同归位，避免长时间来回摆动 |
| 内容表面 | 正文保持稳定填充，复杂图片背景下提高可读性；不对每个列表项启用真实透镜 |
| 模态 | 使用一层主要玻璃表面和统一遮罩，内部普通行/输入面不重复描厚白边 |
| 微纹理 | 内置非图片背景从 `0.055` 收至初始值 `0.015`；用户图片不额外叠斜纹；关闭微纹理的对照画面也应能辨认玻璃边缘 |
| 圆角与间距 | 沿用连续圆角语言；条目以 16dp、分组 24dp、弹层 28dp 为基础，胶囊为半高；间距统一为 4/8/12/16/24dp |

先清理重复轮廓和不正确的来源，再微调透明度。保留现有蓝色主色及课程分类色；文字对比目标为 4.5:1，必要图形/控件边界为 3:1。对比不足时优先补局部可读性底色，不以大幅加粗所有白边解决。

### 5.3 动效体系与打断规则

继续使用 Compose `Animatable`、弹簧和现有 SDF 物理。建立明确用途的共用配置，不以单一时长控制所有动作。Compose 弹簧适合在目标变化时保持运动连续性。[Android：Customize animations](https://developer.android.com/develop/ui/compose/animation/customize)

| 动作 | 初始规格 | 触发与结束规则 |
| --- | --- | --- |
| 普通按压 | 80-120ms 内建立明显反馈 | 不等待业务请求；取消时恢复，不提交动作 |
| 按钮/滑块随动 | 沿用临界阻尼、高刚度随动基线，`damping=1.0 / stiffness=1100` | 同一手势会话重定目标，避免多份互相竞争的回落任务 |
| 底栏吸附与回弹 | 初始 `damping=0.72 / stiffness=360`，一次可见过冲 | 从当前位置和速度接续；常规操作约 250-450ms 视觉稳定 |
| 选择器分裂/吸收 | 保留当前两自由度物理和几何测试约束 | 主要形变约 250-350ms，细小尾部不超过约 600ms；取消和反向操作继续当前物理状态 |
| 主标签切换 | 180ms 淡入淡出，方向性位移最多 8dp | 使用 `AnimatedContent`；立即响应选择，退出结束释放旧页面，不将五页绘制树常驻 |
| 二级页面 | 240ms 有方向的进入/返回 | 返回恢复原页面状态；支持平台提供的预测性返回进度与取消回弹 |
| 弹层 | 进入弹簧初始 `0.80 / 420`，退出 190ms | 存活到退场结束；有来源时从锚点展开并回收，无来源使用居中过渡 |
| 数字/进度 | 180-240ms | 仅真实数据变化时播放，返回页面不重复从零数起 |

初始数值是第一版实现基线，后续校准必须有相同场景的录屏及性能对照，不进行无依据的全局增大弹性或延长动画。

底栏和分段控件手势拆成按下、水平拖动、成功抬手、取消四类事件。只有成功抬手或辅助功能激活才更新业务选中项；取消回到手势起点的已提交项。手指经过的中间标签只有连续视觉权重，不加载页面、不播放各自完整的选中动画。

底栏收缩初始规则：主内容沿向上方向累计移动 40dp 后收起，反向累计 20dp 后展开；换页、回到列表顶部或点击小胶囊时展开。方向改变重置累计值，忽略横向手势、输入框操作、菜单内部滚动和模态展开期间的滚动。几何沿同一锚点变形，小胶囊在原栏退场完成前已有明确衔接，隐藏层不拦截点击。

### 5.4 图标与触觉反馈

基于项目已有的 Material 图标资源建立圆润线性风格，必要的五个主图标做局部分层矢量，使用 Compose 的矢量组、颜色和变换驱动；不新增整套图标依赖，不直接移植 SF Symbols 资产。

| 入口/操作 | 图形与动作 |
| --- | --- |
| 课程 | 圆润列表；选中时行标记依次填充，文字横线轻微对齐归位 |
| 课表 | 日历；选中时日期格局部填充，日历主体做很小的压缩回弹 |
| 抢课 | 目标/定位类符号；外环和中心点短促聚合，表达任务目标；播放/停止保留给执行按钮 |
| 成绩 | 图表；柱条短暂生长至固定选中形态，表达统计而非收藏 |
| 设置 | 齿轮；约 12 度的小角度转动后归位，局部填充保持选中 |
| 刷新、展开、显示密码 | 刷新只在请求进行时旋转；展开箭头跟随展开进度；眼睛开合/替换连续过渡 |
| 加入队列、开始/停止 | 成功确认后显示一次短勾选反馈；执行图标根据真实运行状态切换，不提前宣告成功 |

主图标可见尺寸以 22dp 为基准，选中缩放先收至 1.06 倍、上移不超过 1dp，辨识度主要由局部填充及内部动作提供。文字字重保持稳定，避免跨阈值突然改变排版。保留透镜覆盖图标时的光学关系，前景不做与玻璃等幅的橡皮拉伸。

可见图标与供折射采样的副本读取同一动画状态，副本不独立启动动画、触觉或可访问性事件。有效选择提交时触发一次轻触觉；失败、禁用、取消及滑过中间项不触发成功反馈，遵从系统触觉设置。[Apple：SF Symbols 动画指导](https://developer.apple.com/design/human-interface-guidelines/sf-symbols)

### 5.5 页面状态与数据展示

- 主界面增加 `SaveableStateHolder`，使用既有账号存储键与路由标识组成作用域。保存滚动位置、当前子标签、学期/周次、搜索、筛选和展开项 ID 等小状态。
- 复用现有课程/课表缓存模式，为传统成绩及新适配路由补齐过程内的成功结果快照。大列表、位图、请求和回调不进入保存状态 Bundle。
- 有可用结果时重入立即展示；刷新只显示局部忙碌状态，避免先清空列表再出现加载页。改变学期/分类、完成选退课或用户刷新时按原业务规则失效。
- 快照与异步结果继续按账号隔离；切换账号时不能出现旧账号画面。密码、Cookie、待确认的破坏性动作不加入通用跨页状态保存。
- 新适配页面的功能差异继续由现有能力条件控制。视觉壳与状态保持一致，不通过展示无效按钮来强行统一页面。

这种分工符合 Android 对小型可恢复 UI 状态与大型业务数据的区分。[Android：Save UI state in Compose](https://developer.android.com/develop/ui/compose/state-saving)

### 5.6 同窗口浮层、弹窗和返回

建立 `GlassWindowHost`：每个实际窗口拥有自己的 Backdrop、GL 来源区域、辅助设置和弹层 Host；窗口内部页面复用环境。现有 `LocalAppBackdrop`、`LocalControlBackdrop`、`LocalModalBackdrop` 等入口继续作为兼容接口，禁止独立 Dialog 窗口意外复用父窗口 GL 锚点。

`LiquidPicker` 的锚定按钮始终保持固定布局高度。展开体和融合桥进入同窗口浮层，保留原 SDF 分裂轨迹；背景内容和确认按钮不随菜单伸长而被推走。浮层跟随锚点位置，优先向下，空间不足时向上，边缘保留 12dp 安全间距，菜单最大高度以 320dp 和实际可用空间的较小者为准，内容内部滚动。

弹层明确分四种呈现，不按动画中每一帧的内容高度反复切换类型：

| 类型 | 使用位置 | 关闭/层级 |
| --- | --- | --- |
| 锚定菜单 | 学期、学校、筛选选项等选择器 | 选择、返回或点击外部关闭；关闭菜单保留其父弹窗 |
| 居中确认 | 退出、清缓存、短提示、简单确认 | 统一遮罩与进退场，确认回调只执行一次 |
| 底部表单 | 添加课程、较长学校配置、背景编辑、日期时间选择 | 限高、正文滚动、操作区可达；输入键盘只扣一次安全区 |
| 二级页面 | 课表设置、学校适配流程及历史等完整工作流 | 页面级前进/返回，保留上级位置，使用窗口内正确来源 |

Host 为每个弹层分配稳定句柄，`dismiss(handle)` 只关闭所属项，退出结束再调用对应回调。旧项的 `onDispose` 或延迟任务不能关闭新项。返回优先关闭最上层菜单，其次弹窗，最后二级页面。

在支持的平台接入 `PredictiveBackHandler`：进度驱动二级页面/表单的返回预览，取消回到原状态，提交后才执行关闭。旧平台保持普通返回。系统返回主屏继续交由系统，不重写为 iOS 手势。[Android：Predictive back](https://developer.android.com/develop/ui/compose/system/predictive-back)

### 5.7 辅助功能和输入

- 底栏和分段控件建立 `selectableGroup`、`Role.Tab`、真实 `selected` 状态和等价激活动作。隐藏绘制副本、零宽退场项不出现在读屏遍历中。
- 工具按钮保留 34-38dp 视觉尺寸，布局/触摸槽位达到 48dp；不通过重叠扩大命中区域。长标签按布局换行或缩短语义明确的显示标签，不随屏幕宽度整体缩小字体。
- 统一监听系统动画缩放和高对比变化，并在窗口恢复前台时刷新。Compose 动画使用系统时钟缩放；自定义物理另外遵守减少动画，避免同一动画重复乘缩放系数。
- 减少动画时直接完成位置、选中与开合状态，关闭形变、色散和图标弹跳；保留清晰状态变化。高对比时提高表面遮挡和前景对比。

### 9.1 自动化与运行验证

| 测试组 | 必测情景 | 判定 |

### 9.2 视觉矩阵

- 尺寸：360×640dp、360×800dp、411×914dp，以及至少一次宽窗口/横屏检查。
- 字体：1.0、1.3、2.0；覆盖长学校名、长课程名、空值和多位数字。
- 系统区域：手势导航、三键导航、刘海/状态栏、键盘显示和关闭。
- 背景：浅色、深色、内置彩色背景、明暗混合图片；额外关闭微纹理做玻璃真实性对照。
- 平台：API 30 回退，API 31/32 独立 GL，API 33+ AGSL。已有 API 32/35 模拟器用于功能与像素初验，不能替代真机性能。

### 9.3 性能标准与证据

使用与 Release 优化方式一致、可分析且使用测试签名的独立 benchmark 构建。分析构建用独立应用 ID，避免覆盖用户正常安装；检查 FileProvider、Intent 和内部组件声明对应用 ID 的兼容。正式签名与版本号不改动。

帧时间使用 Macrobenchmark/Perfetto 的 FrameTimeline 与对应设备刷新率判定，分别保存 UI/渲染耗时、超时帧、采样次数、内存及场景录屏，不沿用当前模拟器异常的 GPU 百分位。

- 60Hz 目标：热启动后的标准交互场景超时帧比例不高于 1%，无由本轮动效引入的超过 50ms 长帧；参考单帧预算 16.7ms。
- 120Hz 设备按 8.3ms 单帧预算单独报告；没有对应真机时标为未验收，不能用模拟器或 60Hz 数据替代。
- 静止控件在进入稳定态 1 秒后，连续 10 秒内不再自行请求 GL 渲染或由工具组订阅空闲帧钟；真实加载、光标和系统事件另列，不混入此场景。
- 快速切页、菜单开合各执行 30 次，退出后临时来源、FBO、位图及页面绘制资源能够释放，内存不随循环次数持续增长。
- 连续操作仍须达到视觉标准。出现超预算时先处理重复工作、失效范围和生命周期，不以删掉分裂效果或全面禁用折射作为验收通过。
