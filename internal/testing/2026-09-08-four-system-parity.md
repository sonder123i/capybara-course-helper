# 四类教务功能对齐记录

## 对齐范围

以原有新正方兼容流程为基准，补齐旧正方、新强智、旧强智的应用入口和运行行为。数据、课程标识、轮次及操作控件均读取学校响应。学校未开放与页面尚未适配分别提示，不将缺失实现归为学校限制。

| 功能 | 新正方基准 | 旧正方、新强智、旧强智 |
| --- | --- | --- |
| 账密登录、验证码 | 保留原有流程 | 三类均已有直接账密链路；两个旧系统支持图片验证码获取、刷新、错误重试和提交 |
| 网页登录回退 | 保留 | 定制认证、额外人机验证可回退；普通图片验证码不再一律要求网页登录 |
| 学校、账号 | 跨学校最多 3 个学生账号 | 相同限制，学校和账号分别隔离会话、队列、目标及状态 |
| 可选、已选、轮次 | 保留 | 使用真实分类及轮次，轮次未开放与读取失败分别展示 |
| 搜索和筛选 | 原有学校动态筛选 | 已加载数据按课程、教师、时间、地点、学分及已公布余量筛选；不伪造学校筛选字段 |
| 选课与退课 | 保留确认流程 | 单门确认、长按多选、批量确认、批量入队；逐门读取新参数再提交；退课需单独确认 |
| 精确目标与智能匹配 | 保留 | 指定教学班或同课程多教学班；同名但课程/轮次不同则暂停，不猜测目标 |
| 队列管理 | 保留 | 手动添加、排序、删除、模式切换、状态及账号独立持久化；手动条目也能即时执行 |
| 重试与暂停 | 保留 | 目标轮次等待开放、余量不足等待、网络退避；验证码、登录失效及结果不明停止后续提交 |
| 定时、后台、通知 | 保留 | 共用前台服务及精确闹钟，校验通知权限、触发时间和账号；定时执行队列，临时目标用于即时执行 |
| 课表及导出 | 原有周视图、设置、ICS 导出 | 共用课表界面、学期查询、周次节次解析、缓存和 ICS 导出 |
| 学期/总体成绩、统计、CSV | 保留 | 总分、绩点、学校统计和已返回分项；统一分项格式，保留非数字说明及 0 分 |
| 历年成绩 | 保留 | 旧正方优先用学校历年按钮，无此按钮时逐学期汇总学校开放的选项；读取不完整时报错 |
| 考试安排 | 保留 | 当前学期查询；空列表与接口错误分别处理 |

## 系统差异

- 新正方保留串行和最多 2 门并行。三个新增系统按账号串行，原因是 App 需要保护共享轮次或 WebForms 状态，并非断言学校不允许并行。
- 新增协议队列间隔至少 500 毫秒，每门最多 1000 轮。智能模式每轮可尝试多个教学班，教学班之间也遵守间隔。精确模式不换班；手动课程保持用户填写的教师与时间约束。
- 学校名额、学分、年级专业、课程冲突、选退课窗口及声明确认始终生效。未知容量显示未公布，不显示为已知空位。
- 自动续期仅在已保存账密且学校未要求人工验证时可完成。两个旧系统要求验证码时，用户需要填写验证码。
- 非标准登录加密、验证码、菜单或操作脚本仍可能超出适配范围。错误会提示适配或人工处理，不承诺任意学校定制页面均可自动操作。
- 成绩分项仅展示学校响应已有内容，不反推或编造分项权重。历史汇总仅涵盖学校开放的学期。

## 可见说明

登录页首屏显示四类教务名称；学校配置展示所选类型的登录方式与限制；设置新增「教务支持与限制」，同时标记当前学校类型。抢课页显示当前系统并行能力、重试范围和智能模式规则。README 同步说明四类教务、账号上限和条件式续期。
