# 界面动效与课程详情验证记录

验证日期：2026-09-12。交付分支：`v2`。本轮按“动效不明显、开始按钮没有折射”的反馈加强已确定的设计，不创建正式发布标签。

## 最终实现

| 区域 | 最终行为与参数 |
| --- | --- |
| 分段栏 | 切换弹簧阻尼 / 刚度为 `0.50 / 360`，松手为 `0.48 / 440`，按压为 `0.58 / 680`；按压缩放 `1.10`，速度形变上限 `0.16`。形变直接读取位置弹簧速度，避免短促切换被第二层速度平滑抹掉。折射、高光和轮廓共用形变。 |
| 底栏图标 | Phosphor Books、CalendarDots、Lightning、ChartBar、SlidersHorizontal，24dp 原生 Compose 分层绘制，动作约 480ms。重复点击当前项只重播图形；拖动预选独立控制颜色和填充，松手后播放动作。可见层、玻璃采样层和收起胶囊共用一份播放状态，离开选中态在 160ms 内收束。MIT 许可保存在应用 assets 中。 |
| 页面分组 | 标题、主要内容、辅助操作共用导航持有的入场时间线；每组 380ms，错开 75ms，最多四组，上移 16dp。父页面只移动 8dp，并提前显现，避免遮住子组件入场。刷新、滚动和普通重组不重播；快速反向切换接续当前状态。 |
| 必要退场 | 菜单和展开区约 170ms，动作在菜单完全回收后执行；重新打开会取消待执行动作。课程详情约 220ms，从实际当前位移、缩放继续退出。下拉选择器保留原有融合和回收。 |
| 开始按钮 | 64dp 尺寸与单层圆弧菜单保持不变。采样源包含壁纸和页面内容，按钮与菜单位于采样源之外；修复此前只采样壁纸的问题。专用材质折射高度 20dp、幅度 28dp、静止下限 0.95；浅色 / 深色表面透明度 0.06 / 0.10，按压进一步减薄。光学触点反馈与整体形变分开，保留长按接管。 |
| 课程详情 | 从被点击的课程卡片展开，460ms 加 40ms 起始延迟，标题、信息、提醒和编辑分组进入。高度随内容变化，上限为可用高度的 85%，正文内部滚动。22sp 标题，时间和地点优先，窄屏 / 大字号 / 长地点纵排，横屏压缩顶部。自定义课程底部固定编辑，删除移入更多菜单，依次等待菜单与详情退出后复用删除及撤销。 |

被点击卡片的窗口坐标在打开详情时固定，避免相邻周的同 ID 课程覆盖动画起点和焦点返回目标。复用现有数据、提醒和导航接口，没有新增持久化字段。关闭系统动画时直接显示最终状态；玻璃关闭和高对比度策略继续生效。

## 真实折射证据

受控斜线、棋盘纹和位图背景分别覆盖浅色 / 深色、静止 / 按压、玻璃关闭。像素判定在按钮内部排除文字图形和边缘，检查原本亮条纹位置出现暗条纹（或反向）的位移，避免把遮罩变亮误判为折射。

| 背景 | 浅色静止 / 按压的位移像素比例 | 深色静止 / 按压的位移像素比例 |
| --- | --- | --- |
| 斜线 | 约 0.370 / 0.317 | 约 0.370 / 0.319 |
| 棋盘纹 | 约 0.355 / 0.436 | 约 0.352 / 0.435 |
| 位图 | 约 0.037 / 0.108 | 约 0.042 / 0.107 |

实际抢课界面的浅色和深色截图中，开始按钮均能折弯后方卡片边界及清空日志图标。平滑浅色壁纸缺少高对比边界，视觉强度仍会比受控纹理柔和；玻璃关闭时使用实心回退。

AGSL 与 API 31/32 使用的离屏 GLES 渲染路径共享专用材质参数及短边 40% 位移上限。GLES 编译、渲染和光学参数测试在 MuMu / API 35 上通过；本轮没有完整 API 31/32 操作系统设备运行证据。
