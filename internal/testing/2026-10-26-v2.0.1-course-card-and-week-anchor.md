# 课表卡片排版与「现在是第几周」验收（v2.0.1）

> 验收日期：2026-10-26 · 基线 v2.0.0 (20000) → v2.0.1 (20001)
> 环境：MuMu 12（x86_64 / API 35，adb 7555）· JDK 17.0.16 · Gradle 9.3.1

## 一、用户反馈

1. 课表卡片里的地点被压成「长楼…」「应…」，1.x 能显示「长名楼 / 406」。
2. 1.x 课表设置的「现在是第几周」很好用，v2 没有。
3. 想确认应用内更新是否可用。

## 二、根因

### 2.1 地点被省略

v2 换基线到上游 v1.0.128 后，卡片内容变成三段：课程名 → 教师 → 地点，且地点由
`ScheduleLocation.fit()` 处理：楼名放不下时直接 elide（`长楼…`），只保证房间号完整。

1.x 的卡片只有两段：课程名（≤3 行）+ 地点（≤2 行自然折行），不排教师行。七列均分后
每列内容宽约 42dp，两行足够放下「长名楼 406」这类地址，所以观感更完整。

### 2.2 短地址的校区前缀漏裁

`ScheduleLocation.compact()` 原先在开头判断 `normalized.length <= 12` 就直接返回，
「示例校区 南操场」刚好 12 字，校区前缀被原样带进卡片，把楼名挤到第二行。

### 2.3 第几周反推缺失

1.x 的入口在 `ScheduleSettingsScreen`（commit `a020756`），v2 重建该页时只保留了
「第一周开始日期」的日期选择器，反推入口没有一起搬过来。

## 三、改动

| 位置 | 改动 |
|---|---|
| `ui/screen/ScheduleScreen.kt` | 卡片移除教师行；课程名 `maxLines=3`、地点 `maxLines=2` 自然折行；`rememberFullCoursePeriodHeight` 改用同一套行数预算（原先为「课名+教师+两行教室」预留，行高被抬高） |
| 同上（地点） | 两行仍放不下时按 9sp → 8.1sp → 7.3sp 缩字号，优先保住楼栋与教室号，缩到底才交给 `Ellipsis` |
| `schedule/ScheduleLocation.kt` | `compact()` 先裁「XX校区」与括号注释、再判断长度，短地址不再漏裁 |
| `ui/screen/ScheduleSettingsScreen.kt` | 基础设置新增「现在是第几周」行 + `GlassOptionWheelDialog` 滚轮；`semesterStartOverride` 为 0 时回落到本机保存值 |
| `schedule/ScheduleDates.kt` | 新增 `firstWeekDateForWeek(now, week, weekStart)`：从本周第一天往前推 N 周，跟随周一/周日起始 |
| `ui/route/ScheduleRoute.kt` | 无改动——反推复用 `onSemesterStartChange`，提醒与桌面组件的 timeBase 一起刷新 |

`assets/2026-10-26-week-number-picker.png`

`ScheduleDates.weekAt()` 回算为 1，与日期选择器写同一个入口。

### 4.3 自动化

| 层 | 结果 |
|---|---|
| JVM 单测 | 1414 项 / 0 失败 / 4 跳过（新增 `ScheduleDomainTest` 两个反推用例） |

### 4.4 顺带修掉的过期断言

`headerUsesParentWidthAndWeekdaysStayAlignedWithEveryCourseColumn` 里的
`onNodeWithText("第 24 周")` 在上游把周次标签改成「第 」+ 数字 + 「 周」三段式后
（`ef56586`）必然找不到节点。改为按 `schedule-header-week` 行容器校验 bounds。

## 五、后续追加（同批交付）

| 需求 | 处理 |
|---|---|
| 关掉匿名使用统计 | `UsageNotice()` 在 `ENABLE_ANONYMOUS_USAGE_STATS=false` 时直接不渲染；设置页「数据与安全」里的统计开关同条件隐藏。上报层（`UsageReporter.eligibleBuild`）本来就是关的，这次把告知弹窗和开关一起收掉 |
| 关掉统一登录适配 | 登录页与设置页的入口按 `ENABLE_SCHOOL_SERVICE_BACKEND` 隐藏。该功能提交到作者后端，本发行版没有这个服务，入口留着只会让用户等一个不会来的回复 |
| 基础设置上移 | 「基础设置」整块移到「课前提醒」（`SemesterReminderSection`）之后、「课程安排」之前，开学日期/第几周/每天节数不再被作息预设压到页面下半截 |

设置页新顺序：课前提醒 → 基础设置 → 课程安排 → 课表显示 → 自习时间 → 桌面组件 → 已添加的组件 → 自定义课程 → 作息预设 → 课表数据 → 节次时间。

## 六、遗留

- 教师名从卡片移出，课程详情/日程视图仍完整显示；`ScheduleAdaptationDeviceTest`
  增加了「卡片不残留教师节点」的断言。
- 地点两行都放不下的极端地址仍会省略，这是 42dp 列的物理上限；缩字号已经把
  「长名教学楼 406」这类 6 字楼名纳入可显示范围。
- 统计与统一登录适配的底层实现都保留在库里（R8 会裁掉未引用分支），
  想恢复只需把 `SelfHostConfig` 对应开关改回 `true`。
