# 更新公告规范

> 适用于 `release-notes/vX.Y.Z.md` 的 `## notes` 区块——它会原样出现在
> 应用内更新弹窗、GitHub Release 正文与 Gitee Release 正文。
> `## changelog` 是开发记录，可以写细节，不进用户视野。

## 硬约束

1. **最多 3 行**，一行一件事。用户是在等更新，不是读说明书。
2. **每行不超过 45 个汉字**。超过就说明这件事该拆或该删。
3. **不出现任何真实身份信息**：
   - 学校名、校区名、楼栋名、教室号
   - 课程名、教师名、学号
   - 具体的截图数据、真实地址
   需要举例时用抽象说法：「长楼名」「教室号」「两位数节次」。
4. **不写实现细节**：类名、方法名、参数名、版本号比较逻辑、文件路径。
5. **不写体积、包大小、架构名**，除非这次更新本身就在解决体积问题。
6. **不写「修复了一些问题」这类空话**。要么说清修了什么，要么不写。

## 推荐写法

- 一句话说「用户能感知到什么变化」，而不是「我们改了什么代码」。
- 动词开头：「课表卡片重新排版…」「新增…」「移除…」。
- 数字用中文习惯：「三行」「两行」，不写 `maxLines=3`。

## 反例（v2.0.2 初版，已废弃）

```
课表卡片回到 1.x 的排版：课程名最多三行、地点两行，教师信息移到课程详情。
七列窄卡片里「长名教学楼 406」不再被压成「长楼…」，楼栋与教室号都留在卡片上；
短地址的校区前缀也会被裁掉。
```

问题：出现真实楼名与教室号；一行塞了三件事；「七列窄卡片」「校区前缀」是内部视角。

## 正例

```
课表卡片重新排版：课程名最多三行、地点两行，长楼名不再被省略号截断，教室号始终可见。
课表设置新增「现在是第几周」：填本周周次即可反推第一周日期，课前提醒同步生效。
移除匿名统计弹窗与「统一登录适配」入口，基础设置移到课前提醒下方。
```

## 自检

发版前跑一遍（与 `scripts/release.sh` 同一条管线）：

```bash
awk -v want="notes" '$0 ~ "^## " want "[[:space:]]*$" { i=1; next } /^## / { i=0 } i' \
  release-notes/vX.Y.Z.md | sed '/^[[:space:]]*$/d'
```

人工确认：行数 ≤ 3、无地名/课名/人名、无代码标识符。

自动化检查（脱敏词表可扩展）：

```bash
grep -nE "校区|教学楼|楼[0-9]|[0-9]{3,4}室|大学|学院" release-notes/vX.Y.Z.md
```

命中即需改写——除非它出现在 `## changelog` 里（允许开发记录保留具体例子）。
