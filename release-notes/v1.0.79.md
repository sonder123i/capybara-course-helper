# v1.0.79

## notes

新增问卷中心，可在应用内查看、搜索和填写问卷，支持收藏、浏览历史及手动填写标记。
重要问卷支持可关闭的轻提醒，离线可查看缓存，填写前会联网确认问卷状态。
新增启动首屏设置，可选择课程、课表、抢课、成绩或设置作为启动页。
教务网页登录新增网址输入与学校入口搜索，支持正常跨域认证跳转。
补齐强智新版教务的验证码输入与刷新，改善登录入口和配置识别异常时的处理。
修复部分正方教务的分类与列表加载异常，减少展开教学班时的重复请求。
手动抢课队列可指定教学班，并同时匹配教师和上课时间；不同教学班保留独立队列状态。
修复会话检查初始化异常与旧回调处理，避免错误提示登录失效。
问卷记录保存在当前账号本机，入口点击遵守匿名统计开关；答卷与真实提交结果以问卷星为准。

## changelog

本版本包含 v1.0.77 之后的全部应用改动。v1.0.78 发布流水线已在发布前取消，其问卷功能一并纳入本版本。

### 问卷中心

- 设置新增问卷中心，支持搜索、分类、推荐、进行中与已结束筛选，展示简介、发布方、预计用时、截止时间和封面。
- 收藏、浏览历史、手动填写标记和提醒记录按账号与学校隔离保存在本机，返回列表保留筛选和滚动位置；离线可查看缓存，开始填写前重新确认发布状态。
- 新增独立问卷 WebView，支持进度、返回、刷新、复制链接、系统分享、浏览器打开、文件选择及页面恢复，保留链接参数和正常认证跳转。
- 重要问卷每份提醒一次、每次进入应用最多提示一份，支持关闭轻提醒；问卷入口点击跟随匿名统计开关，不代表问卷星真实提交。
- 适配深色模式、关闭玻璃和减少动态效果，修正详情背景重叠及离线提示可见性；配套问卷发布、学校投放、定时管理和匿名点击统计后端已部署。

### 启动与网页登录

- 新增启动首屏偏好，可选择课程、课表、抢课、成绩和设置；首次进入按偏好显示，活动恢复仍保留当前页面。
- 教务网页登录增加网址输入、关键词搜索和返回学校入口，允许正常网页跨域跳转；导出的 Cookie 仍限定为所配置的教务地址。
- 强智新版登录改从公共入口获取表单，支持验证码提交、刷新和失败反馈，并保留表单实际提交地址与隐藏参数。
- 捕获教务自动识别与登录初始化阶段的异常，避免未选择适配器时中断登录流程。

### 选课与教学班队列

- 兼容正方首个分类写在 first* 隐藏字段的选课入口，补齐分类、轮次参数与显示名称，按教务脚本期望的字段构造列表和教学班请求。
- 展开教学班时优先复用课程行已有协议参数，减少重新加载入口、分类和课程列表的重复请求。
- 手动添加队列支持教学班名称，并结合教师、上课时间筛选；手动目标未匹配时不回退到其他教学班或旧缓存编号。
- 教学班条件纳入队列身份、持久化、复制、状态显示及去重，未填写教学班条件的旧队列保持原有行为。

### 会话稳定性与验证

- 尚未识别或未知的教务配置不直接创建适配器进行会话检查；初始化异常不误判会话失效，旧请求回调不影响新一轮检查。
- 补齐教务验证码、分类参数、网页登录导航、教学班匹配、启动页与会话检查测试，并纳入剩余工程配置和验证素材。
- 完整源码的本地 JVM 测试 396 项通过、3 项条件跳过，Debug 与 AndroidTest APK 编译通过，Lint 无错误；本次按要求不执行设备验证。
