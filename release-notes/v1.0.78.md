# v1.0.78

## notes

设置新增问卷中心，可在应用内查看并填写问卷星问卷。
支持搜索、分类、进行中与已结束筛选，查看发布方、预计用时和截止时间。
新增收藏、浏览历史和手动填写标记，按账号保存在本机，返回列表保留筛选与查看位置。
重要问卷支持可关闭的轻提醒，每份只提醒一次，每次进入应用最多提示一份。
问卷页面支持刷新、复制链接、分享、浏览器打开和文件选择；离线可查看缓存，填写前会重新确认问卷状态。
问卷中心适配深色模式、关闭玻璃与减少动态效果，入口点击统计跟随匿名统计开关。
手动填写标记与入口点击次数不代表真实提交，答卷和提交结果以问卷星页面为准。

## changelog

### 问卷中心与个人记录

- 在设置的“应用与支持”中新增问卷中心，支持搜索、分类、置顶推荐和进行中、已结束筛选，展示简介、发布方、预计用时、截止时间及可选封面。
- 新增收藏、浏览历史、手动“我已填写”、撤销标记和清空历史，按账号与学校隔离保存本机记录，返回列表保留筛选和滚动位置。
- 支持缓存时间展示和离线重试，进入填写前重新检查服务端发布状态；前台自动刷新间隔至少 5 分钟，不增加静置轮询。

### 应用内填写与提醒

- 新增独立问卷 WebView，支持进度、返回、刷新、复制链接、系统分享、浏览器打开、文件选择和页面恢复；保留链接参数及正常认证跳转。
- 设置入口显示未读红点，重要问卷每份提醒一次、每次进入应用最多提示一份；轻提醒可关闭，并避开已有登录、更新等提示。
- 更新匿名统计说明，问卷入口点击遵守统计开关，不作为问卷星真实提交统计。

### 界面与配套服务

- 复用现有玻璃卡片、子页面和筛选控件，适配深色模式、关闭玻璃及减少动态效果；详情页绘制独立壁纸背景，离线提示固定在筛选区下方。
- 配套后端已部署问卷发布管理、按学校投放、定时生效与截止、匿名点击去重和 CSV 导出功能，保留原学校适配服务。

### 验证

- 本地 Debug APK 与 AndroidTest APK 编译通过，Android JVM 测试 368 项通过、3 项条件跳过，其中问卷相关测试 15 项通过。
- 后端 TypeScript 检查和 48 项测试通过，生产 D1 迁移、公开接口与管理员鉴权已验证。
