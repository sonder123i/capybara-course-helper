# v1.0.80

## notes

修复课表按开学日期显示周数的回归，兼容旧版保存的非周一日期。
修复课表首次加载和恢复页面时周数被覆盖的问题，修改开学日期后正确跳转，并保留手动浏览的周次。
申请适配和问卷中心改用独立域名，改善国内网络下的访问兼容性。

## changelog

本版本包含 v1.0.79 发布后的课表周数修复与学校服务域名调整。

### 课表周数

- 旧版保存的开学日期按所在周的周一读取，避免非周一日期被判为无效并回到第 1 周。
- 兼容只有节次时间的学期日历，以及早期尚未保存开学日期的迁移记录；补齐日期时保留已设置的节次时间、账号和学期隔离。
- 显示周数统一跟随当前学期日历，避免旧设置在页面恢复时覆盖已经浏览的周次。
- 区分日历请求的目标周与用户滑动后的周次回传，修复初始分页和旧回调覆盖目标周的问题；修改日期或切换学期时重新定位。
- 新增旧日历兼容、延迟日历加载、分页恢复、连续切周和日期更新的回归测试。

### 学校服务域名

- 学校适配申请、已适配学校目录和问卷接口统一使用 `https://school-api.hidisiwa.xyz`。
- 后台部署 Custom Domain，由 Cloudflare 管理域名解析和 HTTPS 证书；继续使用原服务、D1 数据库和管理员鉴权。
- 原 workers.dev 入口保留供尚未升级的客户端使用。
