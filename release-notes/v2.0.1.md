# v2.0.1

## notes

课表卡片回到 1.x 的排版：课程名最多三行、地点两行，教师信息移到课程详情。七列窄卡片里「长名教学楼 406」不再被压成「长楼…」——地点在 9sp 排不下时自动缩到 8.1sp 或 7.3sp，楼栋与教室号都留在卡片上；短地址的校区前缀也会被裁掉。
课表设置新增「现在是第几周」：不知道开学是哪天，填本周是第几周就能反推出第一周日期。它和「第一周开始日期」写同一个入口，开始时跟随「每周第一天」，课前提醒与桌面组件同步生效。
体积提醒：更新仍按设备架构分发，arm64 包约 111MB，建议在 Wi-Fi 下安装。
