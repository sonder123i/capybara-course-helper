## notes

课表左上角直接显示日期，点它可以切学期、直接跳到任意一周；下面那行会说明现在是第几周，没设开学日期时会写「开学日期待设置」而不是什么都不说。
日视图不再只看今天：顶部日期条点哪天看哪天，左右滑是一天一页，最上面写着今天一共几堂、还剩几堂。
顶栏右边四个小按钮收成一个「更多」菜单：同步课表、导出课表、添加课程、桌面组件、课表设置。往上滚顶栏收起后，菜单里会多出「切换视图」和「回到今天」两条。
新增应用内添加桌面组件：进「桌面组件」可以直接请求把组件放上桌面；桌面不支持这种添加时会告诉你长按桌面怎么加，不会点了没反应。
「周课表」组件下线，换成「今日时间轴」：从今天起往后几天的课按上课时刻排成一列，每天标出日子，正在上的那一节高亮。桌面上还留着周课表的话，把它删掉再添加「今日时间轴」就行。
课表设置新增「显示周末」，周末没课的学期可以只留周一到周五五列。你用的是日视图还是周视图、有没有显示周末，都会按账号记住。

## changelog

本版本两件事：课表页整体对齐上游 v1.0.87 的形态（日期入口、日/周各自翻页、顶栏收成菜单、日视图 agenda 化），以及「周课表」组件下线换成「今日时间轴」。小组件的渲染实现没有采用上游那套，仍然是本仓库自己的三个 Glance 组件。

### 头部：日期成为一级入口

`WeekHeaderCompact` 的标题列从「第 N 周 + 学期分段控件」换成「日期 + 周次状态」两行，学期切换移入弹窗。

- 点标题弹出 `ScheduleCalendarPanel`（日期与学期）：`本学期 / 下学期` 分段、`< 选择周次 >` 前后翻、1–25 周网格直接跳。
- 副标题按状态给话：`开学日期待设置` / `尚未开学` / `下学期 · 第 N 周` / `本学期已结束`。它与既有一次性弹窗、`LocalSemesterAnchorNotice` 内联条并存，缺锚点这件事仍然不许静默。
- 右侧原来 5 枚玻璃芯片（日/周、上一周、下一周、导出、设置）换成 `日 | 周` 分段控件 + `SystemActionMenu`。翻周改由横向滑动与弹窗承担。
- 收起态（`collapseFraction >= 0.5`）分段控件整块淡出，其入口出现在菜单最前两条（切换视图、回到今天）。
- 日期条从只读变成可点：`ScheduleDateStrip` 每列 `weight(1f)`，与网格共用 `scheduleGridPadding()` / `scheduleTimeColumnWidth()` 这一对函数——横向几何只有一处定义，星期与课程列才继续对得齐。选中与今天都用主色，今天额外带圆点。
- 翻到别周时时间列那一格出现「今天」按钮。

### 统一 pager 与日视图 agenda 化

`ScheduleScreen` 的周视图 pager 与独立的日视图合成一个 pager，页数随模式变化：周视图 25 页（一页一周），日视图 175 页（一页一天）。

- 页码换算 `pageOf / weekOf / dayOf` 一律以 `renderedDayView` 为准。`ScheduleWeekPagerSync` 保持只认「第几周」，页码换算留在视图侧，未改动这个有测试的类。
- 换视图分两拍：淡出 → 翻转渲染模式并 `withFrameNanos` 让出一帧 → 落页码 → 淡入。**让帧这步不能省**：`scrollToPage` 读的是上一次布局算出的页数，不让帧就会被旧的 25 页钳住，日视图里第 40 页会落到最后一页。
- 「正在上课」「下一节」「还剩几堂」统一由 `ScheduleAgenda` 算（绝对毫秒，不是节次序号），日视图与网格共用同一份，不会出现摘要说还剩两堂、网格里那节已画成下课。节次时间取页面正在显示的 `periodTimes`，与网格同源。
- 日视图新增 `ScheduleDayList`：日标题、`今日 N 堂 · 还剩 M 堂 / · 已结束 / · N 堂周次待核对`（非今天则「当日」）、无课与越界的分叉话术、下一节课的标记。
- `showWeekend` 只影响周视图列数（`dayCount` 贯穿 `ScheduleGrid` / `TimetableLayout` / `TimetableBackground` / 日期条）。日视图一天一页，日期条必须照旧摆满 7 格，否则翻到周六周日时选中项落在条外。

### 显示偏好按账号存

新增 `ScheduleDisplayStore`（`schedule_display`）：`dayView` 与 `showWeekend` 按 `currentAccountStorageKey` 各存一份，账号为空时拒写——本轮之前有过一次「登出把本地课表变成读不到的孤儿数据」，归属键与登录态必须分开这条不再重犯。**默认值是周视图**，与上游 `dayView = true` 刻意不同。

### 小组件：周课表下线，换成今日时间轴

整周网格在桌面尺寸下可读性差（七列八节、字号 9sp），换成从今天起往后几天的时间轴：左侧上课时刻、一枚课程色点、右侧课名与教室；每天标出日子（跨周时写真实星期几而不是「明天」），正在上的一节高亮，整列 `LazyColumn` 可滚动。今天已下课的课退出队列。

- 新增 `WidgetToday.timeline()`，`cellsForWeek` / `WidgetCell` 与 `weekGridRows` 那套「按高度反推行数」的推导一并删除（可滚动列表不再按高度截断）。`courseEndMillis` 泛化成 `timeOnDay(daySample, zone, time)`，起止两端与跨天共用。
- **接收者类名 `WeekWidgetReceiver` 原样保留**，只换内容与 label / provider 资源。系统记录的是组件名，改名会让桌面上已有的实例升级后变成「不可用」的灰块。这条约束写进了 `TimelineWidget.kt` 与清单注释。
- 补上「下课闹钟」（`WidgetRefreshScheduler` + `nextRefreshAt`）：整列都按「现在几点」排，系统定时刷新最短 30 分钟，不自定闹钟高亮会一直停在上一节。
- 新增应用内入口 `ScheduleWidgetPicker`：列出本仓库三个组件，文案取自 `widget` 模块的 label / description，尺寸写真实的 4×2 / 4×2 / 5×3；`requestPinAppWidget` 不可用时用 `GlassToaster` 说明长按桌面添加。预览走静态图（Glance 无法像 RemoteViews 那样在应用内实时摆出来），「今日时间轴」暂无实拍图，该卡片只有文字，没有伪造示意图。

### 真机上验出来的两处

- 标题列上的 `clip(RoundedCornerShape(14.dp))` 会把贴着左下角的「第 N 周」切掉一个四分之一圆（14dp 在 3.25 密度约 45px）。已移除并加注释禁止再加回来——它只影响点按高亮的形状。
- 日期标题的测量沿用 `bodyLarge.copy(fontSize = 26.sp)`，继承了主题 24sp 行高，而渲染写的是 31sp：量小画大，`Column` 把剩余高度往下传，被挤掉顶部的正是副标题。系统字体 1.0 时被 60dp 行高下限掩盖，1.3 时削掉约 4.5dp。抽出 `headerDateStyle(collapse)` 让测量与渲染同源，与 `weekdayStyle` 同一套路。星期行余量按真实构成（圆点 + 两处间距 + 选中底衬）从 12dp 提到 14dp。
