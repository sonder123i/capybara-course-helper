# v2.0.0

## notes

架构大版本：换基线到上游 v1.0.128，一次性并入上游 8 个月演进——CAS/WebVPN 统一认证、更多正方与强智兼容修复、课表与提醒能力大扩容；1.x 的三种桌面组件继续可用，本发行版依旧不连接任何上游作者服务。
插件平台改为仅本地导入：支持本地导入与管理 .zfplugin 插件包，9 个教务协议包（新/旧正方、新/旧强智、金智、乘方、树维、超星、青果）随包内置、离线可用，装好即用。
课表与提醒：课程名与教师完整显示、每周起始日与多套作息预设按账号设置、缓存优先秒开，整学期课前提醒一键配好，上课自动静音、下课恢复。
应用内更新换签名清单与断点续传、GitHub/Gitee 双线路自动切换；检查更新在渠道未发布时提示已是最新、不再误报换网络；问题反馈改走 GitHub Issues；选校面板支持 1777 所高校拼音直搜、有适配的标星；移除地图、公告中心与问卷中心入口。

## 换基线说明

- 上游来源：znjhahaha/zhengfang-apk @ 124fc8e（v1.0.128 基线），GPL-3.0。
- 本发行版不连接上游任何服务：插件目录、地图、油猴代理、反馈、统计、问卷全部切断；更新使用本项目自有端点（GitHub Pages 主 / Gitee 备），问题反馈改走 GitHub Issues，公告中心与问卷中心入口已移除。
- 1.x 用户原位覆盖升级，学校、账号、课表、队列与已读状态保留（迁移审计见 internal/testing/2026-10-26-v2-data-migration-audit.md）。
- 体积警示：因内嵌浏览器引擎与本地推理组件，安装包约 110MB/架构（地图 SDK 已物理移除，arm64 实测 111MB；1.x 约 5MB）。更新通道默认按设备架构下发对应包。
