# v2.0.0

## notes

架构大版本：本发行版换基线到上游 v1.0.128，一次性获得上游 8 个月演进的全部能力，同时保持卡皮巴拉的自建体系与零作者服务依赖。

- 接入校园插件平台（仅本地导入模式）：支持从本地导入 .zfplugin/.eduplugin 插件包、停用与回退；内置六类教务协议（新/旧正方、新/旧强智、金智、乘方，另含树维 EAMS、超星智慧教务、青果等 TS 协议包）离线可用，不再需要任何外部插件目录。
- 教务能力大幅扩展：学校统一认证（CAS/SSO）、WebVPN 登录、更多正方/强智兼容修复、选课列表渐进加载与加载更多。
- 课表：完整显示课程名与教师（不截断）、每周起始日按账号设置、多套作息预设、日视图日期条整周滑动、当前课程倒计时组件（课间/明天模式）、缓存优先秒开。
- 提醒与自动化：整学期课前提醒一键设置、上课自动静音（下课恢复、支持单双周与调停课）、考试安排查询（继承上游原生考试页）。
- 应用内公告中心：未读徽标、搜索、分类筛选、重要公告弹窗（修订后重新提醒）；数据源为本项目自有公告源。
- 应用内更新升级：签名清单（ECDSA）+ 断点续传 + 暂停恢复 + GitHub/Gitee 双线路自动切换。
- 会话体验重做：会话全局复用、缓存优先不挡内容；本发行版额外关闭了主动会话巡检（惰性过期）——不发起请求就不会弹「正在恢复登录状态」；账号被禁用/锁定等永久失败不再反复自动重试，防止学校端锁定账号。
- 桌面组件双体系并存：1.x 的今日课程/今日明日/今日时间轴（Glance）继续可用且数据续命；上游的三种 RemoteViews 组件（单课/双课/倒计时）新增可选。
- 错误报告页、玻璃视觉细节、大量上游修复全部包含。

## 换基线说明

- 上游来源：znjhahaha/zhengfang-apk @ 124fc8e（v1.0.128 基线），GPL-3.0。
- 本发行版不连接上游任何服务：插件目录、地图、油猴代理、反馈、统计、问卷全部切断；更新与公告使用本项目自有端点（GitHub Pages 主 / Gitee 备）。
- 1.x 用户原位覆盖升级，学校、账号、课表、队列与已读状态保留（迁移审计见 internal/testing/2026-10-26-v2-data-migration-audit.md）。
- 体积警示：因内嵌浏览器引擎与本地推理组件，安装包约 130MB/架构（1.x 约 5MB）。更新通道默认按设备架构下发对应包。
