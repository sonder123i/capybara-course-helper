## notes

本次发布合入 v2 分支，应用名称统一为“教务助手”，补齐多类教务、课表管理和界面交互。
教务适配：支持新正方、旧正方、新强智、旧强智，补齐账密登录及旧系统图片验证码获取、刷新和重试；定制认证保留网页登录入口。
课程操作：四类教务共用可选与已选课程、搜索筛选、单门及批量选退课、队列排序、精确目标、智能匹配和定时任务，具体开放能力以学校为准。
任务恢复：目标轮次未开放时继续按设置等待；网络异常退避重试；遇到验证码、登录失效或结果待确认时暂停，避免重复提交。
账号与会话：切换学校、账号或重新登录后隔离旧请求和页面状态，已保存账密时按学校要求尝试续期；所有学校合计最多使用 3 个学生账号。
课表管理：新增自定义课程编辑、时间冲突提示、删除撤销、学期起始日期与节次时间设置，改进周切换和日历导出。
课程提醒：可为课程开启上课前 15 分钟提醒，编辑、删除、账号切换和设备重启后按课程状态重新计算。
课程详情：改为紧凑信息卡，从点击的课程卡片展开，优先显示时间和地点；底部突出编辑，删除放入更多菜单，长内容可滚动。
成绩与考试：统一学期成绩、总体成绩、已返回的成绩分项、考试安排及 CSV 导出；区分学校未公布数据与查询失败。
抢课工作台：64dp 玻璃开始按钮支持真实背景折射，长按展开单层圆弧菜单，可滑动选择、松手执行。
界面动效：底栏更换 Phosphor 分层图标，重复点击可重播；增强分段栏果冻回弹，五个主页分组入场，菜单和详情连续退场。
主题与布局：支持跟随系统、浅色和深色主题，改进启动衔接、预测返回、窄屏和大字号布局，修复图片壁纸顶栏白雾及下拉玻璃显示。
学校配置：添加与编辑共用自动识别和四类教务选项，设置中可查看当前学校的支持范围与统一登录适配申请。
匿名统计：首次展示说明，可在设置中关闭；仅上报随机安装标识与应用版本，不上传学校、学号、账号或课程内容。
遇到问题可在设置中提交反馈；学校定制认证及特殊操作页面仍可能需要适配。

## changelog

### 四类教务与课程操作

- 接入新正方、旧正方、新强智、旧强智的统一协议层，读取学校实际返回的轮次、分类、课程、教学班及操作参数；保留原有新正方与统一认证兼容流程。
- 补齐新增系统的账密登录；旧正方支持标准 RSA 登录，两个旧系统支持图片验证码获取、刷新及错误重试，定制认证可回退网页登录。
- 对齐可选 / 已选课程、搜索筛选、单门与批量选退课、批量入队、手动队列、排序、精确目标、智能匹配和定时任务。未知容量显示“未公布”，跨轮次同名课程不会自动当成同一目标。
- 队列按账号保护轮次和表单状态，支持轮次等待、网络退避及停止条件；结果不明时核对已选课程，验证码、失效登录和人工确认会暂停后续提交。
- 统一课表、学期 / 总体成绩、学校返回的成绩分项与统计、考试安排、ICS / CSV 导出；旧正方历年成绩使用学校开放的按钮或学期选项，不编造缺失数据。
- 学校配置统一自动识别、四类教务选择、编辑兼容和支持说明；提供统一登录适配申请与历史入口。应用名称统一为“教务助手”。

### 会话恢复与状态隔离

- 统一会话版本校验、失效清理、自动与手动续期；切换账号或 Cookie 后丢弃旧请求回调，防止旧页面覆盖新账号数据。
- 隔离学校、账号、队列、目标、缓存及弹层状态；改进缓存提示、列表稳定身份、页面恢复和空闲渲染。
- 保留所有学校合计最多 3 个学生账号的规则，修正绑定与恢复边界；已保存账密的自动续期仍遵守学校验证码和人工确认要求。

### 课表、课程详情与提醒

- 自定义课程使用稳定身份，修复旧数据的缺失 / 重复 ID；支持课程编辑、非阻断冲突提示、删除及 5 秒撤销。
- 统一学期起始日期、周次和节次时间解析；周切换跟随手势并保留纵向位置，修复 ICS 周日偏移和课程文本转义。
- 增加默认关闭的课前 15 分钟提醒，按账号、学期和课程隔离；编辑、删除、同步、权限、开机及时间变化后重算，接收时复核课程与提醒状态。
- 课程详情按内容确定高度，上限为可用高度的 85%；时间与地点优先，窄屏、大字号及长地点纵向排列，教师和周次使用紧凑信息行。
- 自定义课程底部固定编辑，删除移入顶部更多菜单并等待完整退场后执行；详情从被点击卡片展开，支持内部滚动、拖动关闭、预测返回取消及焦点恢复。

### 玻璃界面、主题与动效

- 抢课工作台改用 64dp 玻璃圆钮和单层圆弧菜单，支持长按原地松手、拖动预选、松手执行和取消；开始按钮采样壁纸与实际页面内容，降低表面遮罩，使背景折射可见。
- 五个底栏图标采用 Phosphor 线面分层设计，选中后播放一次，重复点击当前项仅重播图形；可见层、玻璃采样层和收起胶囊共用播放状态，保留 MIT 许可。
- 分段控件增强按压、速度形变及弹簧回弹；连续切换、反向拖动和尺寸变化继承当前状态，折射、高光和轮廓使用同一形变。
- 五个主页共用分组入场时间线，滚动和刷新不重播；菜单、展开区域与详情在退场后移除或执行操作，减少重复的大幅位移。
- 新增跟随系统 / 浅色 / 深色主题，联动原生窗口、WebView、系统栏及玻璃缓存；保留自定义壁纸参数，修复课表和成绩顶栏的白雾、接缝及下拉玻璃显示。
- 改进启动页与应用内 Logo 的衔接、顶栏触区、筛选锚点和窄屏 / 大字号可达性；系统关闭动画时直接呈现最终状态。

### 匿名统计与工程

- 增加可关闭的匿名安装统计，首次展示说明；仅上报随机安装标识和版本，按北京时间每日成功一次，调试 / 演示构建不计数，标识不参与系统备份。
- 新增 Cloudflare Workers、D1 与 Access 管理页面，展示累计设备、今日活跃和近 30 天活跃；管理访问使用邮箱验证和服务端 JWT 校验。
- 增加 UiPreview / benchmark 构建、协议样本、单元回归、设备操作测试与验证文档。发布前本地 JVM 312 项通过、3 项授权环境用例跳过；MuMu 去重后 62 项通过、1 项条件跳过。
- 发布流程增加构建前检查和公告同步：校验更新日志与公告文件，在 APK 和版本信息发布完成后追加本次公告，保留历史，失败时让流水线明确报错。
