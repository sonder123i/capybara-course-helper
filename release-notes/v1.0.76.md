# v1.0.76

## notes

本次更新集中修正 Android 12 系列的玻璃显示、拖动手感和课表排版。
底栏、分段栏和数值滑块直接跟随手指，改善反向拖动与松手衔接。
分段栏的弹性收敛一档，减小按压放大和滑动拉伸，保留轻微回弹。
修复课程标签书本图标的三角形异常，以及底栏玻璃中图标停留在上一帧的问题。
修正抢课开始按钮的背景折射位置和圆弧菜单轮廓，减少重复采样与大面积离屏计算。
课表顶栏按可用宽度和字号调整排列，星期与课程列准确对齐。
长教室名完整换行显示，课程格高度随内容调整，不再只显示两行。
课程详情更快打开，保留卡片展开、拖动关闭、内部滚动和删除撤销。

## changelog

### 玻璃显示与拖动

- 底栏、分段栏、数值滑块和颜色滑块直接使用指针位置及事件时间戳，点击与松手弹簧继承当前位置和速度；底栏拖回原标签也会准确归位。
- 分段栏切换阻尼 / 刚度调整为 `0.60 / 400`，松手为 `0.62 / 480`，按压为 `0.64 / 680`；按压缩放降至 `1.08`，速度拉伸上限降至 `0.13`。
- 修复 Android 12 的 Books 复合路径闭合后相对起点解析异常，保留 Phosphor 原图形和分层动画。
- API 31/32 折射按实测四角与当前坐标采样，修正圆弧菜单溢出和形变错位；对称轮廓保留简洁计算，没有色散时只采样一次。
- 开始按钮采样限制在周围区域，展开菜单时再扩大；大菜单的模糊光学底层最多回读 160,000 个像素。
- 底栏背景与图标分别缓存并直接合成，滚动和图标动画只采集变化的图层；图层录制完成后通知更新，结果位图不再被后续帧改写。
- 修正 API 33+ 玻璃色散的具名传参，避免误启用深度效果。

### 课表与课程详情

- 顶栏根据实际父容器宽度和文字测量自适应，放得下时保留原两列布局，窄屏和大字号再换行；星期与课程列统一偏移。
- 教室取消两行省略，统一节次高度随完整文字增加，保持时间轴、网格和课程跨度对齐；状态图标移到地点下方。
- 详情弹窗立即开始展开，主体约 220ms、内容约 240ms 完成，保留返回取消、主题切换、焦点恢复和删除撤销。

### 验证与已知限制

- 本地 JVM 317 项通过、3 条件跳过；Lint 无错误，Debug、Release、UiPreview 和 AndroidTest 编译通过。
- API 32 功能回归 44 项通过，API 35 复核 16 项通过；涵盖真实纹理折射、图标同步、反向拖动、长教室名、字号适配及实际操作录屏。
- 模拟器对照仍存在切页与滚动慢帧，本次不宣称整体帧率改善或卡顿完全解决。完整结果见 `docs/testing/2026-09-13-api32-fixes.md`。
- 本次归档覆盖 v1.0.75 之后的全部应用修正、回归测试及相关文档，不重复归档既有功能。
