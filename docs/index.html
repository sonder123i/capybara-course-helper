卡皮巴拉教务助手

一只情绪稳定的卡皮巴拉，替你盯着余量。选课抢课、课表成绩，全都在一个 App 里。

下载 APK
当前版本 1.0.0 · Android 7.0 及以上

能做什么

选课与抢课

即时执行、定时任务、捡漏盯课三种模式。按关键词搜、按类别筛，余量和教师都显示。

周视图课表

课程自动配色，支持自定义课程与冲突提示，可导出 .ics 到系统日历。

成绩与考试

按学期查询，GPA 自动计算，附带考试安排与 CSV 导出。

液态玻璃界面

折射、色散与高光实时计算，按下去会形变。跑不动的老设备自动降级，不会卡死。

背景随你换

预设渐变、纯色，或直接用相册里的图。模糊和蒙版两根滑条，配色跟着背景自动适配深浅。

多教务支持

新正方、旧正方、新强智、旧强智四类教务系统，学校地址可自行添加。

怎么装

1
下载 APK点击上方按钮，浏览器会保存安装包
2
允许安装未知来源应用系统会弹提示，按引导打开对应权限
3
添加学校并登录选择教务类型，填写账号密码，需要验证码时按提示输入
