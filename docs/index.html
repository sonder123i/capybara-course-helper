核心能力

该有的都有，抢课尤其认真

不是把教务网页塞进一个壳。离线优先，课表成绩缓存到本机；抢课按账号保护轮次与表单状态，带网络退避与停止条件。

抢课三模式

有空位就点——即时执行拼手速；知道几点开抢——定时任务到点自动发包；热门课满了——捡漏盯着名额，有人退立刻顶上。支持批量选退、队列排序、指定教师与时段、同轮次内智能换教师。

桌面小组件

不解锁，也知道今天上什么

三个 Glance 组件，不依赖应用常驻后台——组件自己按日期与周次算出今天的课，下课那一刻自动刷新，上完的课自动让位给后面的课。

  • 今日课程 —— 课名、地点、时间与配色条；小屏显示下一节，大屏最多六节
  • 今日与明日 —— 两栏并排，提前知道明天要不要带书
  • 周课表 —— 周一至周日 × 节次网格，单双周自动过滤，当天列高亮

教室与时间各占一行，校区前缀自动裁掉；全上完显示「今天的课都上完啦」。演示模式下也能用，退出演示会清掉桌面上的演示课。

数据与隐私

不采集、不上传任何使用数据

上游版本会采集随机安装标识与应用版本并上报到作者自建服务。本 fork 在装配层集中切断了这些通道——开关只控制「要不要发这个请求」，不改动任何业务逻辑。

上游版本默认行为

  • 随机安装标识 + 版本号上报作者自建统计服务
  • 用户反馈内容上报远端
  • 远端公告拉取、学校适配申请后端
  • 应用内更新指向作者仓库

本版本当前行为

  • 统计通道已关闭，不会有任何统计请求发出
  • 反馈内容不离开本机
  • 公告与适配后端关闭，仅保留自建更新检查
  • 账号密码经 Android KeyStore AES/GCM 加密，仅存本机
  • 最多绑定 3 个学生账号，纯本地计数；卸载即清除
兼容性

支持四类教务系统

共用同一套选退课、队列、精确目标、智能匹配与定时任务入口，以及课表、成绩、考试和导出功能。应用不会绕过学校限制——验证码、选课声明、结果确认仍需你本人处理。

教务系统登录方式执行与数据限制
新正方账密、图片验证码、网页登录串行或最多 2 门并行；筛选与查询以学校返回内容为准
旧正方标准 RSA 账密登录、验证码获取与刷新按账号串行保护表单状态；体育课与选退课使用学校当前控件
新强智直接账密登录；额外人机验证可转网页登录按账号串行保护轮次上下文；无开放轮次时仍可查询已选、课表与成绩
旧强智账密登录、图片验证码获取与刷新按账号串行保护轮次上下文；开放分类与权限由学校决定
安装

三步装好

当前版本 1.1.2，安装包 5.81 MB。

1

下载 APK

从本页按钮或 GitHub Releases 下载 app-release.apk。

2

允许安装未知来源

系统会弹提示，按引导给浏览器或文件管理器打开「安装未知应用」权限。

3

添加学校并登录

在 1777 所学校里搜到你的学校，确认教务类型，填账号密码。需要验证码时按提示输入。

注意：包名与原版 com.tyust.course 不同，两者可以共存，但学校配置与账密需重新登录一遍。若之前装过同包名的 debug 版，需先卸载才能安装 release 版（签名不同无法覆盖）。
